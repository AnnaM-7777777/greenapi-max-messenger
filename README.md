# MAX Messenger

Веб-приложение для обмена текстовыми сообщениями через мессенджер MAX, реализованное с использованием сервиса [Green API](https://green-api.com/max).

## 📋 Описание

Приложение реализует полноценный чат с возможностью отправки и получения текстовых сообщений в реальном времени через API GREEN-API для мессенджера MAX

## ✨ Функциональность

- **Авторизация** по учетным данным GREEN-API (`idInstance`, `apiTokenInstance`) с валидацией на сервере
- **Создание чата** по номеру телефона
- **Отправка текстовых сообщений** через метод `sendMessage`
- **Получение сообщений** в реальном времени через long-polling (`ReceiveNotification`)
- **Сохранение истории** переписки в localStorage
- **Защита от дубликатов** сообщений
- **Кнопка выхода** для смены аккаунта

## 🛠 Стек технологий

- **React 19** — UI-библиотека
- **TypeScript** — строгая типизация
- **Vite** — сборщик и dev-сервер
- **Axios** — HTTP-клиент для работы с API
- **CSS Modules** — стилизация
- **Green API** — сервис для интеграции с MAX

## 🚀 Установка и запуск

### Требования

- Node.js 18+
- npm или yarn

### Шаги установки

1. Клонируйте репозиторий:

```bash
git clone https://github.com/AnnaM-7777777/greenapi-max-messenger.git
cd greenapi-max-messenger
```

2. Установите зависимости:

```bash
npm install
```

3. Настройте переменные окружения - создайте файл .env в корне проекта и добавьте ваши учетные данные из личного кабинета Green API:

```env
VITE_ID_INSTANCE=ваш_id_инстанса
VITE_API_TOKEN_INSTANCE=ваш_api_токен
```

⚠️ Важно: Файл .env содержит секретные данные и не должен публиковаться в репозитории, добавлен в .gitignore и не попадает в репозиторий. Для тестирования можно ввести данные через интерфейс приложения.

4. Запустите dev-сервер:

```bash
npm run dev
```

5. Приложение будет доступно по адресу: http://localhost:5173

6. Сборка для продакшена (опционально)

```bash
npm run build
```

## 🚀 Использование

- Откройте приложение в браузере
- Введите idInstance и apiTokenInstance из личного кабинета GREEN-API
- Нажмите "Войти в чат" (данные будут проверены на сервере)
- Введите номер телефона получателя в формате 79991234567
- Нажмите "Начать чат"
- Отправьте сообщение в поле ввода внизу
- Получите ответ от собеседника в реальном времени

## 🔧 Технические особенности
### Long-polling для получения сообщений
Используется метод ReceiveNotification с таймаутом 5 секунд. При отсутствии новых сообщений сервер возвращает 408, что корректно обрабатывается.

### Защита от дубликатов
Реализован механизм защиты от повторного добавления одного и того же сообщения через Set с idMessage.

### Валидация credentials
Перед входом в приложение данные проверяются на сервере GREEN-API через метод getStateInstance.

### Сохранение истории
Сообщения сохраняются в localStorage и восстанавливаются при перезагрузке страницы. Реализована защита от перезаписи истории пустым ответом сервера.

### Правильная работа с очередью
Уведомления удаляются из очереди через DELETE /deleteNotification/{receiptId}, что предотвращает повторную обработку.
